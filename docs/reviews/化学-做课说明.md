# 做一张化学活页

你在“活页课本”项目里做一张化学活页：课本上的某张图、某个实验，在课本页上“立起来”，成为能动手做的 3D 交互实验。你只负责分给你的那一课。

## 地方
- **工作目录**：`<工作区>`（分支 `<分支>`）。shell 的当前目录可能被重置回主仓库，所以每条命令前都要先 `cd` 进来。
- **开发服务器**：已经开着，地址 `http://127.0.0.1:<端口>/`，打开 `?book=<书 id>#live=<课 id>`。不要启动或停止任何服务器，也不要碰别的端口。
- **课本 PDF 路径**：`python3 -c "import sys; sys.path.insert(0,'tools'); from pdf_paths import pdf_path; print(pdf_path('<书 id>'))"`。
  - PDF 页序（从 0 起）= 印刷页码 + 4，选必 2 是 + 2；
  - 用 PyMuPDF 读文字、取坐标，要看图就渲染成图片再看。

## 先读，必须
1. `QUALITY.md`：通用原则，内容正确是第一位。
2. `DESIGN-化学.md`：化学的标准，每一节都要过。
3. **DESIGN-化学.md 里点名的初中样板课**：打开它们，照着手感、卡片、钻进去看去做。做完拿自己的课和样板课并排比。
4. 和你这课最像的、已经做好的化学活页，照它们的结构。
5. 用到的公共件，都在 `src/lessons/kit/`：
   - 课程骨架：`chemlesson.js`、`lessonbar.js`；
   - 器材：`tubebench.js`、`chem.js`、`chemfx.js`、`labops.js`、`props.js`；
   - 拖动：`interact.js`；
   - 钻进去看：`microworld.js`。

## 规矩
- **只写你那一课**：`src/lessons/<id>.js`；新器材写进 `src/lessons/kit/<id>-parts.js`。
- **公共件不改现有行为**：实在要加东西（比如在 MOL 里加一种离子），只做追加，并在报告里写清楚。
- **登记文件不动**：PLAN、`tools/bbox-overrides.json`、`src/content/books.json`。bbox 不对的话，在报告里写出正确值。
- **不做 git 操作**：不 commit，不 stash，不切分支。
- **不自作聪明**：不加课本没有的步骤、器材、读数、提示框、播放控件。微观和概念色属于标准，可以有。
- **文字**：界面文字用中文，不用「」，用“”或者加粗。
- **兼容 iOS 15 / Chrome 87**：不用 `Array.prototype.at`、`Object.hasOwn`、`structuredClone`。

## 写代码时容易踩的坑
- 注释写在一行代码后面时，别把后半句代码也吞进注释里。
- `textPlate` 的画布固定 512 宽，字号要按牌子的大小算。
- `draggable` 的 `plane: 'xy', offset: z` 是 z = offset 那个竖直面，`onDrag` 写进状态的 z 要和它一致。qaFlow 里 drag 的 `to` 也要落在这个平面上。
- `fresh()` 里要包含状态的全部字段，演示前后会比较。sandbox 的 `apply` 要按换回来的状态把器材摆好。
- 题卡只在 `!S.demo` 时打开。`reset()` 要关题卡、清记录、调 `W.ui.relock()`、`bar.undo(...)`，镜头回到全景。
- `flame2` 返回的是 Group，要 `group.add`，每帧调 `update(t)`。在浅色纸面上，加法混合的东西看不见。

## 自己检查，交之前都要做
1. 按 DESIGN-化学.md 第六节的第 2 条，逐条跑脚本，都要通过。端口用 `LB_PORT=<端口>`。
2. 用 Read 打开全尺寸截图看：
   - 演示连拍：`tools/flowshot.mjs <id> --demo`；
   - 关键现象：`--upto=<步骤名>`；
   - 钻进去看：逐帧看。
   
   flowshot 的单张写在 `/tmp/lbqa/fs/`，别的进程也可能写同名文件，拍完马上看，或者复制到自己的目录。
3. 和样板课并排比三样：手感、卡片、钻进去看。

## 报告：最后一条消息，中文，简短
- **做了什么**：场景、步骤、模型（关键数字和依据）、做错的后果、微观；
- **课本依据**：页码和引文；
- **自检结果**：每条脚本的输出、看过哪些截图、改掉了什么；
- **公共件**：改没改，改了哪里；bbox 要不要改；
- **面向学生的文字**：列出所有面向学生的文字，包括状态栏、提示、卡片、字幕、记录表、面板，一条一行；
- **还拿不准的地方**。
