## 审核结论与范围

此前版本不能按完成品交付。自动加载与步骤通关没有覆盖装置连接、液封、微观与宏观一致性、课本裁切这些语义问题。本轮逐项核查并修复，保留复核脚本与本地截图，不把“102 个活页能加载”当作本课科学性或视觉质量的证明。

审核覆盖：首次进入与可选预测、加热、提前关火、冷却读数、封存、开塞、取粉、移送、倒入、塞回、强热、再次冷却、结果对照、答题、原教材结论页、两阶段微观入口及动态反应、教师演示完整播放与中途退出、重置、1440×900 与 1280×800 桌面视口、离线加载。

边界：这是教材原理的交互教学模型。取样口、旋塞与炉门操作是为交互加入的简化，不声称复刻拉瓦锡原器材和全部操作；没有计算真实热平衡、汞蒸气、泄漏或流体压差。合并仅提供计算与课本性质的对照，不冒充完成了实物气体转移。手机竖屏未纳入本轮桌面交付验收。

## 知识点逐项核对

主要依据：用户已有的人教版《化学》九年级上册（2024 年版）第 30–31 页，PDF 零基页索引 36–37，图 2-2。

| 知识点 | 教材与模型处理 |
|---|---|
| 加热时间与现象 | 教材记载连续加热 12 天，一部分银白色汞变为红色粉末，气体体积减小；页面把长过程加速呈现，不把秒数或中间进度称为实测速率。 |
| 正反反应 | 加热汞与氧反应形成氧化汞；强热氧化汞得到汞和氧。两向反应中 Hg、O 原子守恒。 |
| 气体性质 | 教材记载剩余气体不能支持燃烧和供给呼吸。所得氧气性质不同；两部分合并后的性质与空气相同。页面标明这是课本观察，未伪造本模型实测的燃烧实验。 |
| 体积关系 | 收回氧气与原来减少量对应。所有模型记录按同温同压折算；没有把受热时气体体积当作冷态读数。 |
| 21% 的来源 | 21% 来自第 31 页现代空气组成；79 份包括氮气和其他未反应成分，不称为 79% 纯氮气。100/79/21 为理想化示例，不是拉瓦锡原始数据。 |
| 历史认识与现代认识 | 拉瓦锡当时将剩余气体看作氮气；现代空气还有稀有气体等成分。结论中保留这一区别。 |
| 物质形态 | 左侧过量汞仍为银白色液体，氧化汞为红色固体；强热后汞重新出现。微观 HgO 单位只是组成示意，不代表真实晶体结构。 |

补充交叉核对：[拉瓦锡《Elements of Chemistry》第一部分第三章](https://www.gutenberg.org/files/30775/30775-h/30775-h.htm)。原著明确记录冷却和温压折算，也说明收集粉末与保留全部气体往往需要重复实验；其历史体积记录并非这里的 100/79/21。此来源用于确认模型边界，不用历史著作中的旧理论代替现代知识。

## 复核证据

- 真实鼠标：两种桌面视口均走通整条操作链；检查每件可拖物、步骤目标可达性、桌面以下几何、管路与实体相交及场景截图。
- 独立几何检查：两根管路进入钟罩时都低于罩口；最低外缘分别约 0.00777、0.00729，高于槽底 0.003；槽壁和槽底相交数为 0。旋塞关闭前后轴心不变。
- 状态检查：提前关火有较少的反应量；提前停止强热收回较少氧气；热态不记录冷态体积；未移入粉末或未塞好瓶塞时不进入密闭强热流程；开塞后不允许破坏剩余气体封存。
- 微观检查：左侧初态 16Hg + 5O₂，终态 6Hg + 10HgO；右侧 10HgO → 10Hg + 5O₂。动态运行与重新进入后的终态均核对，旁观氮气未参与反应。
- 演示：脚本验证完整演示及中途退出恢复学生状态；另以真实时间播放并逐镜头截图，检查器材动作与学生流程一致。

## 仍保留的简化

1. 不是历史装置的工程复原。取样开口、旋塞和炉门的交互映射均有界面说明。
2. 不计算真实反应速率、温度、汞蒸气或压差。液面只讲变化方向，数字只讲归一化的氧量守恒。
3. 气体性质来自课本对照，没有额外模拟燃烧、呼吸验证；气体合并也是结果对照。
4. 微观粒子数和固定位置是可读的组成示意，不是分子动力学或 HgO 晶体结构。

这些边界不能再以“只是示意”为理由掩盖悬空、穿模、错误连接、错误知识点或未走通的操作。
