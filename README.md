# 活页课本 · Livebook

让课本活起来：在书页上，亲手探索课本里的知识。

课本平放在桌上，可以点、拖着翻页；翻到有互动内容的那一页，点一下插图，它就在书页上“站”起来，等你动手去试、去改、去发现。

**在线体验：<https://livebook.derekfuture.club>**（电脑和手机都能打开）

网站上不放课本书页。想对照原书页，可以在书里自行导入这一版教材的 PDF，见下面的“看原书页”。

## 现在有什么

人教版初中物理、化学和初高中地理，共 12 册、134 张活页（“活页”就是书页上一张能动手的插图）：

- **物理** 3 册：八年级上册、八年级下册、九年级全一册，65 张活页，覆盖 20 章和八上的绪言，从声、光、热到力、电、磁
- **化学** 2 册：九年级上册、九年级下册，37 张活页，从氧气、二氧化碳、燃烧到金属、溶液和酸碱盐；其中 17 张能“钻进去看”分子、原子和离子怎么变化，每张都有“老师演示”
- **地理** 7 册：初中七年级上册、八年级上下册，高中必修第一、二册和选择性必修 1、2，32 张活页，从地球运动、地形、喀斯特、断层褶皱到锋面、气压带风带、城市和工业区位
- 物理、化学的每张活页是一次完整的探究：可以先猜一猜 → 动手做、自己读数 → 从自己的数据里得出规律 → 掀开课本上的结论对照，盖一个章；地理的每张活页分三步：想一想（一个生活里的问题）→ 动手看 → 对照课本原文

首页是一张书桌，每一科一摞课本。点地理进到“地理世界”：一颗按此刻真实太阳照亮的地球，7 册课本围成一圈立在下面；地球上的小旗指向书里的活页，点下去书翻到那一页、活页在书页上打开；地球还能换成昼夜、板块、气压带来看。喜马拉雅、长白山两面旗会先俯冲到真实地形（卫星影像 + 高程），再把那一块切出来放到课本上，变成活页的模型。

手机上也能打开书桌和地理世界；活页本身按电脑和投影设计。首页的“下载离线版”是一个双击就能打开的网页，放进 U 盘、没有网也能用（导入过的课本 PDF 会一起打包）。

之后会扩展到更多教材、年级和学科。

## 看原书页：导入课本 PDF

网站上不放课本书页（版权归出版社），书里是我们自己画的占位页，活页照常能用。想对照原书页，可以自行导入这一版教材的 PDF：

1. 打开一本书，点右上角的“导入课本”，选择 PDF（也可以直接拖进页面）。
2. 导入时会核对页数（见上表），对不上会提醒，可能不是同一版。
3. PDF 只存在这台电脑的浏览器里，不上传。刷新、关掉浏览器以后都还在；换浏览器或换电脑要重新导入。

手边没有 PDF 的话，最简单的办法是用 AI 助手，比如 WorkBuddy、豆包工作、千问办公：把教材名称告诉它，让它找一个下载教材的 skill，从国家中小学智慧教育平台下载。

## 运行

仓库里不带教材 PDF（版权归出版社），只带章节目录 `*.目录树.json`。教材 PDF 请自己准备（见上面的版本），按 `pdf/<科目>/<版本>/<册>.pdf` 放，和仓库里已有的目录树放在同一个文件夹：

```
pdf/
├── 物理/人教版/  八年级上册.pdf  八年级下册.pdf  九年级全一册.pdf
├── 化学/人教版/  九年级上册.pdf  九年级下册.pdf
└── 地理/人教版/  七年级上册.pdf  八年级上册.pdf  八年级下册.pdf
                  必修第一册.pdf  必修第二册.pdf  选择性必修1.pdf  选择性必修2.pdf
```

每本书对应哪个文件写在 `tools/pdf_paths.py`；运行 `python3 tools/pdf_paths.py` 可以看哪几本已经放好。

然后：

```bash
npm install
pip3 install pymupdf
npm run pages      # 把 pdf/ 里的教材渲染成书页贴图，写到 public/books/<书>/{hi,lo}/（书页只在本地开发时用，网站上只放封面）
npm run dev        # http://127.0.0.1:5188
```

想用别的目录里的 PDF，设环境变量 `LIVEBOOK_PDF_DIR` 指向它（里面的结构和 `pdf/` 一样）。

部署：`./tools/deploy.sh`（Cloudflare Pages；会去掉书页图片，只留封面）。`./tools/deploy.sh --preview` 不上传，在本地 <http://127.0.0.1:5195> 打开和线上一样的版本。
离线版：`node tools/build_offline.mjs` → `dist-offline/活页课本.html`（部署时会先做这一步，放到网站上供下载）。Cloudflare 单个文件不能超过 25 MiB，离线版要控制在这个大小以内。

教材路径按科目、版本和册次排列，例如 `/physics/pep/grade-8-vol-2`、`/geography/pep/selective-compulsory-1`（`pep` 表示人教版）；地理世界是 `/?subject=dili`。深链接：原有的 `?book=wuli-8x` 也可打开这本书（物理 `wuli-8s` `wuli-8x` `wuli-9`，化学 `huaxue-9s` `huaxue-9x`，地理 `dili-7s` `dili-8s` `dili-8x` `dili-bx1` `dili-bx2` `dili-xb1` `dili-xb2`），`#p=23` 翻到 PDF 第 23 页，`#live=lever` 直接打开某张活页，`&pages=placeholder` 在本地假装没有书页图片（看线上没导入课本时的样子）。
键盘：← → 翻页，T 目录，Esc 合上活页；老师演示时空格暂停。

## 目录结构

```
tools/render_pages.py     PDF → public/books/<书>/{hi,lo}/NNN.jpg + book.json（页数、章节 → 页码）
tools/find_bbox.py        根据图注框出插图的位置；手工修正写在 tools/bbox-overrides.json
tools/gen_content.py      PLAN.md + bbox-overrides.json → src/content/books.json（每本书的活页在哪一页、哪个位置）
tools/strip_pages.sh      部署时去掉书页图片，只留封面
src/book/                 3D 书：纸张弯曲翻页、纸堆厚度、贴图分级加载、发光热点；书页从哪来（导入的 PDF、本地书页图片、占位页）、导入课本
src/content/editions.js   每本书对应哪一版教材：书名、页数、平台上的地址
src/home/                 书桌首页：每一科一摞书 + 一件东西 + 桌签；点一科摊开、拿一本进书；继续上次、活页总览、下载离线版
src/world/                地理世界：地球、书圈、看法（昼夜 / 板块 / 气压带）、此刻的时间读数（GeoWorld.js）；俯冲用的真实地形（terrain.js）
src/live/                 把图从书页上揭下来、弹出立体实验；课本插图画风（描边 + 分层上色）；
                          高中地理书里的地球目录（World.js：点旗翻到那一页、活页从地球上长出来，俯冲进来的那块地形落到书页上变成模型）
src/lessons/<id>.js       每张活页一个文件：预测题、结论、场景、物理 / 化学模型、面板控件
src/lessons/kit/          共用的器材和交互：电路、光具座、测力计、磁体、化学玻璃仪器（chem.js）、液体和火焰（chemfx.js）、
                          微观次元（microworld.js）、老师演示和步骤栏（lessonbar.js）、拖拽、读数卡……；
                          地理的旗和章节（atlas.js）、地图标注（labels.js）、岩层贴图（strata.js），以及各张地理活页的模型
src/ui/                   实验面板（预测 / 实验 / 结论、掀纸片、盖章）、3D 标签
PLAN.md / PLAN-chem.md / PLAN-geo.md
                          物理、化学、地理全部计划中的活页清单和完成状态
DESIGN-高中地理.md        地理活页怎么做（探索三步、标注、呈现方式）
tools/geo/                地理用的工具：地形切片、Blender 烘焙模型、每张活页的检查脚本、预览图
tools/build_offline.mjs   离线版（打包成一个 HTML，数据见 tools/offline_data.mjs）
QUALITY.md                一张活页算“做好了”的标准
tools/smoke.mjs、qa.mjs   冒烟测试（每张活页能不能打开）、质检（穿模、拿得到、流程、老师演示）
```

## 再加一张活页

1. 在 `PLAN.md` 的表格里加一行（id、节、图号、PDF 页），运行 `python3 tools/find_bbox.py` 找插图位置，必要时在 `tools/bbox-overrides.json` 里手工修正，再运行 `python3 tools/gen_content.py`。
2. 在 `src/lessons/` 新建 `<id>.js`，导出：
   - `predict`（题目、选项、答案）、`need`（解锁结论的条件）、`conclusion`（课本结论、公式、解释、出处页码）；
     地理活页用 `flow: 'explore'`：`ask`（生活里的问题）、`need`、`conclusion`（课本原文），做法见 `DESIGN-高中地理.md`；
   - `create(ctx)`，返回 `{ group, size, view, mount(ui), update(dt), pointer }`。用 `ctx.ink` 里的 `paint / inked / hull / arrow / polyline` 画，风格就和其他实验一致；器材和交互尽量用 `src/lessons/kit/` 里现成的。
3. 对照 `QUALITY.md` 自查：数据要学生自己读、规律要从学生自己的数据里得出。
