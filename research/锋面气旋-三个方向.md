# 常见天气系统（选必1 第三章第一节，课本第 42–47 页）：三个方向（2026-11-05，给作者选）

课本这一节的图：图 3.2 锋的形成（本身就是一块 3D 示意块）、图 3.3/3.4 冷锋暖锋剖面、图 3.5 等压线分布模式、图 3.6/3.7 气旋反气旋、活动图 3.8（真实亚洲等压线图，甲乙两条锋、P 地）。
学生最常见的误解（见 `锋面气旋-误解考法和数值.md`）：锋前锋后按图面左右分；雨区位置死记；“暖锋一定在冷锋前面”；“高压脊也有锋”；过境前后气温气压顺序背反；“气旋就是台风”；准静止锋的冷暖两侧看反。

## 方向 A：课本图 3.2 那块锋面立起来（只讲“锋”）

- **活法**：空间 + 关系。
- **开场问题**：“天气预报说‘冷空气明天到’，为什么有的城市先下雨后降温，有的城市一直下了好几天？”
- **课本的图怎么变**：
  - 书页上就是图 3.2 的线稿：绿色地面、橙色锋面、冷暖两个箭头。
  - 学生按住冷气团往前推，线稿立成 3D：冷空气像楔子插到暖空气下面，暖空气被抬起来。
  - 沿着锋面翻起云，云里落雨。
  - 换成推暖气团：坡度缓得多（真实比例冷锋约 1:100、暖锋约 1:200，画面上放大坡度并注明），云和雨铺得很宽、在锋前。
- **镜头一站一站**：
  1. 书页上的线稿；
  2. 线稿立起来；
  3. 侧面剖开，冷锋和暖锋并排比坡度和雨区；
  4. 俯冲到锋前的城市甲，站在地上看云压过来、雨落下；
  5. 拉回俯视：地上那条线就是天气图上的锋线符号（三角、半圆）。
- **这里和那里**：
  - 锋前的甲城、锋后的乙城，各有一块小气象牌（气温、气压、天气），锋面过去时实时变；
  - 准静止锋这一站换成一座山挡住冷空气：贵阳（冷气团一侧，连阴雨）和昆明（暖气团一侧，晴）并排看。
- **先暴露直觉**：
  - 先问“雨在锋前还是锋后？”，推过去才发现：雨总在冷气团那一侧；
  - 再问“锋前锋后看图的左右吗？”，换个方向推就明白了：锋前锋后按锋自己往哪走来定。
- **第一个检查点**：书页上的图 3.2 线稿 → 推冷气团 → 立成 3D、暖空气抬升、云翻起来。录视频。
- **好处**：
  - 最贴课本（图 3.2 本来就是立体的，“课本的图就是模型”最直接）；
  - 数都好核对；
  - 第一个检查点最小。
- **不足**：只讲锋，不讲气旋。气旋要另做一张，或者做成方向 B 的第二步。

## 方向 B：一张天气图站起来（锋面气旋，整节）

- **活法**：空间 + 时间 + 关系。
- **开场问题**：“天气预报员看的这张图（等压线图），到底在说什么？明天你这里会刮什么风、下不下雨？”
- **课本的图怎么变**：
  - 书页上是一张虚构区域的等压线图（课本图 3.5 加活动图 3.8 的样子，不画国界）：低压、高压、槽、脊、两条锋、几座城市。
  - 学生一斜书页，等压线变成一片起伏的“气压地形”：低压是盆地，高压是山包。
  - 空气从四周流向低压，一路向右偏转（地转偏向力），在北半球就转成逆时针；到中心汇合往上升，升起来的地方长出云。
- **镜头一站一站**：
  1. 平铺的天气图；
  2. 立成气压地形，空气流起来；
  3. 低压的槽里长出冷锋、暖锋（左冷右暖）；
  4. 拖时间，气旋往东移，锋扫过城市 P；
  5. 从锋上剖开，就是课本图 3.3、3.4 的剖面；
  6. 落到 P 城，看过境前后的天气。
- **这里和那里**：
  - 气旋东边的城市吹偏南风、暖湿，西边的吹偏北风、冷（就是课本活动第 1 题）；
  - 等压线密的城市风大、疏的风小（活动第 2 题）。
- **先暴露直觉**：
  - “高压脊上也会有锋吗？”拉一个脊出来，空气往外散，碰不到一起，没有锋；
  - “台风也是气旋吗？”可以并排放一个暖心的台风比一比，这一项放第二步。
- **第一个检查点**：平铺的等压线图 → 立成气压地形、空气从四周流向低压并偏转、中心上升长云。录视频。
- **好处**：
  - 一张活页讲完整节，正好对上课本的活动题和高考最常见的考法（看等压线图判锋、判风、判天气）；
  - 最像“走进一张图”。
- **不足**：
  - 最难做好看：空气流动的粒子、成片的云；
  - 气流是教学模型，要标明不是真的天气预报；
  - 工作量最大。

## 方向 C：站在城里等一场冷空气（从地面开始）

- **活法**：时间 + 关系，最后用空间揭晓。
- **开场问题**：“只看天，你能猜出是什么天气系统要来了吗？”
- **课本的图怎么变**：
  - 开头不是图，是一座小城的街头：一个小气象站，有温度计、气压计、风向标、雨量筒。
  - 学生拖时间（三天）：暖锋来时，天上的云一层层变低变厚，下起绵绵细雨；冷锋来时，一堵积雨云压过来，大风、降温、雨很急。
  - 气象站一边画出气温、气压、降水的曲线。
  - 学生根据曲线和天空，猜来的是冷锋还是暖锋，再“飞上去”：镜头升到高空，变成课本图 3.3、3.4 的剖面，揭晓答案。
- **这里和那里**：两座城分屏同时看，一座在锋前、一座在锋后。
- **先暴露直觉**：“气温先降还是气压先升？”看曲线自己找。
- **第一个检查点**：街头小城 → 拖时间，暖锋的云一层层压过来，曲线画出来。录视频。
- **好处**：
  - 最有“身在其中”的感觉；
  - 气象员一样读证据，是地理该练的推理。
- **不足**：
  - 离课本的图最远（图是最后揭晓才出现）；
  - 天空和云要真实好看，难度高。

## 我的建议

先做 **A**。理由：
1. 课本图 3.2 本来就是立体的，“课本的图就是模型”在这里最自然；
2. 最常见的几条误解（雨区在哪、锋前锋后、过境前后的变化）都在 A 里能“推一下就看出来”；
3. 第一个检查点最小，最容易先把“好看”的标准立住。

A 做完，B 的第二步（气旋和锋面气旋）可以接着用 A 的锋面模型，不用重做。
