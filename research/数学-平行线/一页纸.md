# 七下 7.2.3 平行线的性质 · 用影子量地球（开工前的一页纸）

## 1. 知识清单（课本第 15–17 页原话）和思维方法

- 探究：画两条平行线 a∥b，任意画一条截线 c，度量八个角；哪些是同位角，度数有什么关系？改变截线 c 的位置，猜想还成立吗？
- 性质 1：两条平行直线被第三条直线所截，同位角相等。（两直线平行，同位角相等）
- 性质 2：两条平行直线被第三条直线所截，内错角相等。（两直线平行，内错角相等）课本由性质 1 和“对顶角相等”推出来。
- 性质 3：两条平行直线被第三条直线所截，同旁内角互补。（两直线平行，同旁内角互补）课本写“请你自己完成推理过程”。
- 例 2（梯形铁片求角）：道理就是性质 3，主线里不另放一块铁片（放进去就成了应用题）。这一点请你定。
- 思维方法：判定反过来想就是性质；用已经得到的性质推出新的性质；用几何把够不着的东西量出来。
- 前面学过、直接用：对顶角相等、邻补角互补、三种角的名字、平行线的判定（含“垂直于同一条直线的两条直线平行”）。

## 2. 世界：埃拉托色尼量地球

约公元前 240 年，亚历山大城图书馆馆长埃拉托色尼。克莱奥梅德斯记下了他的办法：

- 夏至正午，西埃涅（今阿斯旺）的日晷针没有影子，太阳正在头顶；
- 同一时刻，亚历山大城的日晷针有影子，量出来是一整圈的 1/50；
- 两城相距 5000 斯塔德，所以地球一圈是 25 万斯塔德。

原文里关键的一句，就是课本上的这条：“直线落在平行直线上，内错角相等。”他假设太阳光是平行的，两城在同一条经线上。实际两城不完全在同一条经线上；斯塔德有几种长度，折成今天的单位大约 4 万千米，要带“大约”。

## 3. 开头的问题和问题链

**开头的问题**：两千多年前，有人没离开埃及，只靠一根木杆和它的影子，就量出了整个地球有多大。他是怎么量的？

1. 开场站在亚历山大城的正午，木杆脚下一道短影子；转到西埃涅，木杆没有影子，井底被照亮。
   - 问：同一个太阳、同一时刻，为什么一处有影子、一处没有？
2. 太阳很远，照下来的光可以看成平行线。
   - 问：平行线被一根直线截开，角之间有什么关系？（进入课本的探究）
3. 图书馆大厅的屋顶有两个小孔，漏下两束平行的阳光。学生拿一根长杆横在光里，转一转，看两处的角。→ 性质 1。
4. 埃拉托色尼要的是内错角：我们带着推出性质 2；性质 3 交给学生自己推。
5. 回到大地。如果大地是平的，两根木杆都垂直于地面，所以平行；平行的光照下来，同位角相等，两处影子应当一样长。可是不一样。
   - 学生把大地弯过来，直到两处的影子都对上：两根木杆的延长线交在一点，就是地心。
6. 问：地心那个角谁也去不了，怎么知道它多大？
   - 学生把影子的那个角顺着木杆滑到地心，正好填满两城在地心张开的角（内错角）：1/50 圈。
7. 那一瓣地球绕地心转，正好 50 瓣拼满整个地球：一圈是 50 × 5000 = 25 万斯塔德。
   - 正面答掉开头的问题；升华：一根木杆、一句“两直线平行，内错角相等”，量出了整个地球。

## 4. 每一条知识对应的动作

| 知识 | 谁来做 | 动作 |
|---|---|---|
| 探究、性质 1 | 学生 | 转长杆；把一处的角片顺着杆滑到另一处，正好盖住；换个角度再试，还是盖住 |
| 性质 2 | 带着做 | 角片先滑过去（同位角），再转半圈（对顶角），正好盖住内错角 |
| 性质 3 | 学生自己想 | 拿两块同旁内角的角片自己拼；拼成一条直线 = 180°。卡住才给提示 |
| 大地是弯的 | 学生 | 把平的大地往下弯，直到两处影子都对上；两根木杆交出地心 |
| 地心的角 | 学生 | 影子的角片顺着木杆滑到地心，盖住 |
| 量地球 | 学生 | 转那一瓣，一瓣一瓣拼满一圈，数出 50 |

## 5. 最美的一两件事、重拍、封面

- **最美的两件事**：
  - 地上的一道影子，顺着木杆滑进谁也去不了的地心，正好盖住；
  - 50 瓣拼成整个地球。
- **重拍**：
  1. 同位角盖住；
  2. 同旁内角拼成一条直线；
  3. 大地弯过来，两根木杆交于地心；
  4. 影子的角滑到地心盖住；
  5. 50 瓣拼满。
- **封面**：50 瓣拼成的地球，一束束平行的阳光照着它。

## 6. 场景和外形（要比圆周角更有感觉）

- **开场和探究：图书馆大厅**。昏暗的石头大厅，屋顶两个小孔漏下两束平行的正午阳光，空气里有浮尘，看得见光柱。平行线就是这两束光。
- **主模型：一瓣地球**。从地面一直切到地心，立在课本上：
  - 顶面是亚历山大到西埃涅那一条埃及：地中海岸、尼罗河的绿带、沙漠；
  - 两个切面是一层层岩石，尖端就是地心；
  - 平行的阳光从上面斜照下来。
- **两个尺度之间**：从大厅一路升上去，地面越来越弯，变成那一瓣地球。
