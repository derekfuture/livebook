# codex 评审：锋与天气全部阶段（2026-11-05）

**比上一版明显进步：暖锋“锋线没到，你家已经下雨”、准静止锋“两地天气不同”已经能亲手发现。但还不宜作为公众号成品，先修暖空气路径、地面镜头和历史记录污染。**

已读四份材料，用 playwright-core＋无界面 Chrome for Testing，在 1440×900 下实际操作冷锋、暖锋、准静止锋、地面视角、两地拖动及重来。未改项目文件、未提交 git；截图仅存 `/tmp`。当前页面的天气图实际位于**左侧面板**。

**1．严谨性问题，按重要性排序**

1. **暖空气的近地面路径画到了冷空气一侧，这是硬错误。**  
   冷锋应该从右侧暖空气进入抬升路径，暖锋应该从左侧进入；现在两者都从冷侧近地面走到锋线，再折返爬升，容易教成“冷空气自己上升成云”。[路径代码](/Users/scout911/dev/mp/livebook/.claude/worktrees/geo/src/lessons/front.js:153)里的起点符号与注释相反。应修正暖侧起点，保证“暖侧地面→锋线→沿界面上升”连续、不折返；同时裁掉伸出地块的箭头。[暖锋终点截图](/tmp/front-warm-end.png)右侧已能看到箭头飞出地块、出画。

2. **准静止锋明确指错了推动对象。**  
   左栏写“按住左边的冷气团”，场景牌却写“按住暖气团，往右推”，推进箭头也是暖色。[截图](/tmp/front-still-hint.png)。本例既然演示冷空气受山阻挡，就统一为推动冷气团；不能让同一画面给出两个相反指令。

3. **条件说明仍离关键发现太远。**  
   “冷锋来了，先降温还是先下雨”及完成后的“实际”容易被读成普遍规律。当前结论末尾已经补了例外，这点应保留，但应在猜测处直接写“**在这个情境里**”，场景常驻“本例有足够水汽，云雨位置为教学示意”。实际冷锋降水可在锋前、锋后，也可能没有；不能用这次演示替代所有冷锋。[气象课程资料](https://www.weather.gov/media/zhu/ZHU_Training_Page/Miscellaneous/fronts/fronts.pdf)

此外，准静止锋每约 1.4 秒增加一天，应明确写“示意时间已加速”，避免把任意动画节奏当作有物理尺度的模拟。

**2．小白体验最该改的 3 处**

1. **最值得发现的那一刻，容易一拖就过去。**  
   冷锋一次普通拖动就能穿过四个阶段，最后主要靠左栏补读；暖锋“地面仍冷，头顶先下雨”的空间关系又被云遮着。建议不强制停顿、不加答题：锋线接近你家时，突出地面交线与当地雨区，天气牌短暂强调“锋线还没到／已经到了”，保留一条看得清的上升路径。让发现发生在模型里。

2. **“到地上看”现在既看不好，也缺少继续观察的操作。**  
   进入后推进箭头隐藏，没有清楚的继续推进入口；学生很难完成“站在家里，看天气过境”。保留一个轻量的“继续推进／暂停”操作，且沿用当前锋面状态。镜头修正见下一项。

3. **两种锋的对比没有稳定地留在眼前。**  
   完成冷锋、暖锋后，两条长文字时间线不断把内容往下挤，准静止锋结果甚至在首屏外。建议改为两条对齐的紧凑天气带，标出同一个“锋线到家”位置，让“雨在它之前还是附近”一眼可比。猜测保持可选；我全程没猜，也能正常推进，这个方向是对的。

**3．视觉最该改的 3 处**

1. **先修地面镜头：红旗占据画面中央，严重遮挡。**  
   冷锋、暖锋都复现；[暖锋雨中地面截图](/tmp/front-ground-warm-rain.png)里，巨大红旗与旗杆几乎成为主体，房屋和远景消失。把机位移到房屋、旗杆侧前方的空地，校验实际落点和近裁剪；房屋只占一侧小部分，主要视野留给地平线、云底和雨幕。当前这个视角不具备展示价值。

2. **主画面仍显得矮、贴书，暖锋尤其明显。**  
   [暖锋中段截图](/tmp/front-warm-rain.png)中，上半屏大片空桌面，地块和云挤在下半屏；地块虽确实悬浮，但视觉上仍贴着书。应整体上移主体、适度提高观察角度，露出地块与书页之间的空隙，减少底部课本占比。云需有灰色云底与层次，避免一团亮白遮掉锋面、房屋和雨的起点；不必靠继续夸张锋面高度来解决。

3. **标签没有避让，面板也没有为结果预留空间。**  
   两城拖近后，天气牌直接叠字：[截图](/tmp/front-cold-real-end.png)；初始“锋面／冷气团”也拥挤。给两城牌做上下错位＋引线，长天气拆成短行。左栏则固定保留对比区域，折叠已读说明，避免三种锋操作完后结果落到屏幕外。

**4．已确认的 bug，按优先级排序**

| 问题 | 复现与建议 |

| **地面镜头严重遮挡** | 冷锋过境后、暖锋下雨时均被红旗挡住；不是偶发截图问题。 |
